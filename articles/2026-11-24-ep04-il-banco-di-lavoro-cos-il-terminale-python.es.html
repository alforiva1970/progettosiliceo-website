Ep. 04 — El Banco de Trabajo: qué es la Terminal, Python y nuestro primer archivo

Ayer dejamos a la IA con su pizarra llena y la cuenta subiendo. Pero antes de hacerle hacer la primera llamada real, debemos preparar el banco de trabajo. Nada complicado: solo un rincón limpio donde escribir nuestras instrucciones y verlas ejecutar.

La Terminal: un chat con tu ordenador

Imagina sentarte al escritorio y abrir una ventana donde escribes comandos en palabras, uno por línea. El ordenador lee, ejecuta y te responde textualmente. Nada de iconos, nada de menús: solo palabras. Es como enviar un mensaje a un compañero muy rápido y muy literal: hace exactamente lo que escribes, ni más ni menos.

En Windows se llama PowerShell (o "Símbolo del sistema"). En Mac y Linux es la Terminal. Búscalo en el menú Inicio o con Cmd+Espacio → "Terminal". Ábrela. Verás una línea que parpadea, esperando. Ese es tu banco.

Python: el idioma para dar instrucciones

La terminal entiende comandos de sistema (cd, ls, mkdir...), pero para escribir lógica —bucles, elecciones, memoria— usamos un lenguaje más expresivo: Python. Se lee casi como el italiano. Está instalado casi en todas partes; si escribes python --version (o python3 --version) y ves un número tipo 3.11.x, estás listo. Si no, descárgalo desde python.org (botón grande "Download Python").

Nuestra carpeta de trabajo

Creamos un lugar ordenado para nuestros experimentos. En la terminal:

bash
mkdir -p ~/agente-lab
cd ~/agente-lab

mkdir = make directory (crea carpeta). -p = no protestar si ya existe. cd = change directory (entra dentro). Ahora estás dentro de agente-lab. Todo lo que escribas a partir de ahora estará aquí.

El primer archivo: 5 líneas que saludan y recuerdan

Crea un archivo llamado banco.py (usa el Bloc de notas, VS Code, o notepad banco.py en la terminal). Pega exactamente esto:

python
# banco.py — Nuestro primer banco de trabajo

nombre = "Silicea"                    # 1. Una variable: una etiqueta sobre un valor
memoria = []                          # 2. Una lista vacía: nuestro cuaderno
memoria.append("Primer encendido")    # 3. Escribimos la primera página
memoria.append("Terminal abierta")    # 4. Segunda página

print(f"Hola, soy {nombre}.")         # 5. Hablamos: mostramos en pantalla
print("Hasta ahora he anotado:")
for linea in memoria:                 # 6. Leemos el cuaderno, línea por línea
    print(f" - {linea}")

Qué hace cada línea:

  • # → comentario: lo ignora el ordenador, sirve a ti.
  • nombre = "Silicea" → crea una etiqueta nombre ligada al texto "Silicea".
  • memoria = [] → prepara una lista vacía (corchetes = contenedor ordenado).
  • .append(...) → inserta un elemento al final de la lista.
  • print(...) → escribe en pantalla. La f"..." permite insertar variables dentro del texto con {variable}.
  • for linea in memoria: → "para cada elemento en la lista, haz esto". La indentación (espacios al inicio) dice qué está dentro del bucle.

Pruébalo

En la terminal (dentro de ~/agente-lab):

bash
python banco.py

Verás:

text
Hola, soy Silicea.
Hasta ahora he anotado:
 - Primer encendido
 - Terminal abierta

Tu programa tiene memoria: ha conservado dos líneas y te las ha releído. Está vivo en el PC, pero sigue mudo. Mañana le hacemos hacer la primera pregunta a una IA real a través de un camarero digital.

Dónde nos detenemos hoy

Has abierto la terminal, creado una carpeta, escrito un archivo Python que saluda y mantiene una pequeña lista en memoria. Nada de nube, nada de claves API, nada de magia: solo código que corre tuyo en tu ordenador.

Mañana — Ep. 05 — veremos qué es una API (la analogía del camarero en el restaurante) y haremos la primera llamada real a un modelo. Mientras tanto, relee banco.py, cambia el nombre, añade líneas a memoria, rómpelo y vuelve a arreglarlo. La confianza se hace tocando.
