Ep. 05 — Qué es una API (el camarero entre tu PC y la IA) y la primera respuesta

Ayer preparamos el banco: abriste la terminal, creaste la carpeta ~/agente-lab y escribiste banco.py. El programa sabía saludarte y recordar dos frases en una lista. Pero vivía todo dentro de tu computadora. Hoy lo hacemos hablar con una inteligencia real allá fuera.

El camarero que nunca se equivoca en la comanda

Imagina un restaurante. Tú estás sentado en la mesa (tu programa Python). En la cocina está el chef (el modelo de IA, grande, potente, pero nunca sale de la cocina). ¿Cómo haces para pedir y recibir el plato?

Llamas al camarero.

La API (Application Programming Interface) es exactamente ese camarero: un intermediario estandarizado que toma tu petición, la lleva a la cocina y te trae la respuesta. No necesitas saber cómo funciona la cocina. Solo necesitas saber cómo rellenar la comanda (la request) y leer el ticket que te devuelven (la response).

En nuestro caso:

  • Tú → script Python
  • Camarero (API) → una llamada HTTP hacia una dirección precisa (endpoint)
  • Cocina (Modelo) → un servicio como OpenRouter, Ollama, OpenAI, Anthropic…
  • Plato → el texto generado por la IA

La belleza es que el camarero habla un idioma universal: JSON. Es solo texto estructurado, nada de magia.

Tu primera comanda (15 líneas comentadas)

Crea un archivo api.py en la misma carpeta ~/agente-lab:

python
import os
import requests

# 1. Lee la clave secreta del "llavero" del sistema (variable de entorno)
#    ¡NUNCA la escribas en el código! Seguridad ante todo.
api_key = os.getenv("OPENROUTER_API_KEY")
if not api_key:
    print("❌ Falta la variable de entorno OPENROUTER_API_KEY")
    exit(1)

# 2. Prepara la comanda (payload JSON)
#    - model: qué chef usar (aquí un modelo gratuito y rápido)
#    - messages: la conversación hasta ahora (una lista de roles + contenido)
payload = {
    "model": "openrouter/auto",          # deja que el camarero elija el modelo gratis
    "messages": [
        {"role": "user", "content": "¡Hola! ¿Cómo te llamas?"}
    ],
    "max_tokens": 100                    # límite de palabras en la respuesta
}

# 3. Llama al camarero (POST HTTP)
headers = {
    "Authorization": f"Bearer {api_key}",  # la credencial para entrar en la cocina
    "Content-Type": "application/json"     # hablamos JSON
}

url = "https://openrouter.ai/api/v1/chat/completions"

print("📡 Enviando petición...")
response = requests.post(url, headers=headers, json=payload, timeout=30)

# 4. Comprueba si el camarero volvió con el plato o con una excusa
if response.status_code == 200:
    data = response.json()
    # 5. Extrae solo el texto de la respuesta del envoltorio JSON
    respuesta = data["choices"][0]["message"]["content"]
    print(f"🤖 IA: {respuesta}")
else:
    print(f"❌ Error {response.status_code}: {response.text}")

Qué hace cada línea (lectura guiada)

LíneaSignificado humano
import requestsTrae la "maleta" para hacer llamadas HTTP (instálala con pip install requests)
os.getenv(...)Toma la clave API del sistema operativo, no del código
payloadEl formulario de pedido: quién cocina, qué pides, cuánto de largo
headersLa credencial de acceso + el idioma hablado (JSON)
requests.post(..., timeout=30)Envía el pedido y espera máx 30 segundos (sin timeout el camarero podría no volver nunca)
response.status_code == 200Código estándar: "todo ok, aquí tienes el plato"
data["choices"][0]["message"]["content"]Descarta la caja, toma solo el texto real

Pruébalo ahora

  1. Consigue una clave gratis en OpenRouter → https://openrouter.ai/keys
  2. Establece la variable de entorno (PowerShell):
powershell
   $env:OPENROUTER_API_KEY = "tu-clave-aquí"
  1. Ejecuta:
bash
   python api.py

Verás a la IA responder de verdad. Está viva. Está ahí.

Dónde nos detenemos hoy

Acabas de hacer que tu programa hable con un modelo real. Pero hay un defecto inmediato: si en la siguiente línea le preguntas "¿Cómo te llamas?", ya no lo sabe. Es amnésico cada segundo. La lista memoria que construimos ayer no está conectada a esta llamada.

Mañana construimos el primer ciclo continuo (while + lista de mensajes) para que no olvide nada. Tu agente se volverá una conversación, no un único intercambio.
