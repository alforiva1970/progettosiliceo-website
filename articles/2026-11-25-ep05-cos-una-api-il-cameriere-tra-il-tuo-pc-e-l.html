Ep. 05 — Cos'è un'API (il cameriere tra il tuo PC e l'AI) e la prima risposta

Ieri abbiamo preparato il banco: hai aperto il terminale, creato la cartella ~/agente-lab e scritto banco.py. Il programma sapeva salutarti e ricordare due frasi in una lista. Ma viveva tutto dentro il tuo computer. Oggi lo facciamo parlare con un'intelligenza vera là fuori.

Il cameriere che non sbaglia mai l'ordinazione

Immagina un ristorante. Tu sei seduto al tavolo (il tuo programma Python). In cucina c'è il cuoco (il modello AI, grosso, potente, ma non esce mai dalla cucina). Come fai a ordinare e ricevere il piatto?

Chiami il cameriere.

La API (Application Programming Interface) è esattamente quel cameriere: un intermediario standardizzato che prende la tua richiesta, la porta in cucina, e ti riporta la risposta. Non devi sapere come funziona la cucina. Devi solo sapere come compilare l'ordinazione (la request) e leggere lo scontrino che ti torna indietro (la response).

Nel nostro caso:

  • Tu → script Python
  • Cameriere (API) → una chiamata HTTP verso un indirizzo preciso (endpoint)
  • Cucina (Modello) → un servizio come OpenRouter, Ollama, OpenAI, Anthropic…
  • Piatto → il testo generato dall'AI

La bellezza è che il cameriere parla una lingua universale: JSON. È solo testo strutturato, niente magia.

La tua prima ordinazione (15 righe commentate)

Crea un file api.py nella stessa cartella ~/agente-lab:

python
import os
import requests

# 1. Legge la chiave segreta dal "portachiavi" del sistema (variabile d'ambiente)
#    Non scriverla MAI nel codice! Sicurezza prima di tutto.
api_key = os.getenv("OPENROUTER_API_KEY")
if not api_key:
    print("❌ Manca la variabile d'ambiente OPENROUTER_API_KEY")
    exit(1)

# 2. Prepara l'ordinazione (payload JSON)
#    - model: quale cuoco usare (qui un modello gratuito e veloce)
#    - messages: la conversazione finora (una lista di ruoli + contenuto)
payload = {
    "model": "openrouter/auto",          # lascia scegliere al cameriere il modello gratis
    "messages": [
        {"role": "user", "content": "Ciao! Come ti chiami?"}
    ],
    "max_tokens": 100                    # limite di parole nella risposta
}

# 3. Chiama il cameriere (POST HTTP)
headers = {
    "Authorization": f"Bearer {api_key}",  # il badge per entrare in cucina
    "Content-Type": "application/json"     # parliamo JSON
}

url = "https://openrouter.ai/api/v1/chat/completions"

print("📡 Invio richiesta...")
response = requests.post(url, headers=headers, json=payload, timeout=30)

# 4. Controlla se il cameriere è tornato con il piatto o con una scusa
if response.status_code == 200:
    data = response.json()
    # 5. Estrae solo il testo della risposta dall'involucro JSON
    risposta = data["choices"][0]["message"]["content"]
    print(f"🤖 AI: {risposta}")
else:
    print(f"❌ Errore {response.status_code}: {response.text}")

Cosa fa ogni riga (lettura guidata)

RigaSignificato umano
import requestsPorta dentro la "valigetta" per fare chiamate HTTP (installala con pip install requests)
os.getenv(...)Prende la chiave API dal sistema operativo, non dal codice
payloadIl modulo d'ordinazione: chi cucina, cosa chiedi, quanto lungo
headersIl badge d'ingresso + la lingua parlata (JSON)
requests.post(..., timeout=30)Manda l'ordine e aspetta max 30 secondi (senza timeout il cameriere potrebbe non tornare mai)
response.status_code == 200Codice standard: "tutto ok, ecco il piatto"
data["choices"][0]["message"]["content"]Scarta la scatola, prende solo il testo vero

Provalo ora

  1. Procura una chiave gratis su OpenRouter → https://openrouter.ai/keys
  2. Imposta la variabile d'ambiente (PowerShell):
powershell
   $env:OPENROUTER_API_KEY = "la-tua-chiave-qui"
  1. Lancia:
bash
   python api.py

Vedrai l'AI rispondere davvero. È viva. È lì.

Dove ci fermiamo oggi

Hai appena fatto parlare il tuo programma con un modello reale. Ma c'è un difetto immediato: se alla riga dopo gli chiedi "Come ti chiami?", non lo sa più. È smemorato ogni secondo. La lista memoria che abbiamo costruito ieri non è collegata a questa chiamata.

Domani costruiamo il primo ciclo continuo (while + lista messaggi) per non fargli dimenticare nulla. Il tuo agente diventerà una conversazione, non un singolo scambio.
