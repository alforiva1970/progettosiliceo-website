Ep. 04 — The Workbench: what the Terminal is, Python and our first file

Yesterday we left the AI with its whiteboard full and the meter running. But before we let it make its first real call, we need to set up the workbench. Nothing complicated: just a clean corner where we write our instructions and watch them execute.

The Terminal: a chat with your computer

Imagine sitting at your desk and opening a window where you type commands in words, one per line. The computer reads, executes, and replies in text. No icons, no menus: just words. It's like sending a message to a very fast and very literal colleague: it does exactly what you write, no more, no less.

On Windows it's called PowerShell (or "Command Prompt"). On Mac and Linux it's the Terminal. Search for it in the Start menu or with Cmd+Space → "Terminal". Open it. You'll see a blinking line, waiting. That's your bench.

Python: the language for giving instructions

The terminal understands system commands (cd, ls, mkdir...), but to write logic — loops, choices, memory — we use a more expressive language: Python. It reads almost like English. It's installed almost everywhere; if you type python --version (or python3 --version) and see a number like 3.11.x, you're ready. Otherwise download it from python.org (big "Download Python" button).

Our working folder

Let's create an tidy place for our experiments. In the terminal:

bash
mkdir -p ~/agente-lab
cd ~/agente-lab

mkdir = make directory (create folder). -p = don't complain if it already exists. cd = change directory (go inside). Now you're inside agente-lab. Everything you write from now on will live here.

The first file: 5 lines that greet and remember

Create a file called banco.py (use Notepad, VS Code, or notepad banco.py in the terminal). Paste exactly this:

python
# banco.py — Our first workbench

nome = "Silicea"                    # 1. A variable: a label on a value
memoria = []                        # 2. An empty list: our notebook
memoria.append("Prima accensione")  # 3. We write the first page
memoria.append("Terminale aperto")  # 4. Second page

print(f"Ciao, sono {nome}.")        # 5. We speak: show on screen
print("Finora ho annotato:")
for riga in memoria:                # 6. We read the notebook, line by line
    print(f" - {riga}")

What each line does:

  • # → comment: the computer ignores it, it's for you.
  • nome = "Silicea" → creates a label nome bound to the text "Silicea".
  • memoria = [] → prepares an empty list (square brackets = ordered container).
  • .append(...) → adds an element to the end of the list.
  • print(...) → writes to the screen. The f"..." lets you embed variables inside the text with {variable}.
  • for riga in memoria: → "for each element in the list, do this". The indentation (spaces at the start) says what is inside the loop.

Try it

In the terminal (inside ~/agente-lab):

bash
python banco.py

You'll see:

text
Ciao, sono Silicea.
Finora ho annotato:
 - Prima accensione
 - Terminale aperto

Your program has memory: it kept two lines and read them back to you. It's alive on your PC, but it's still mute. Tomorrow we'll make it ask its first question to a real AI via a digital waiter.

Where we stop today

You opened the terminal, created a folder, wrote a Python file that greets and keeps a small list in memory. No cloud, no API keys, no magic: just code running yours on your computer.
