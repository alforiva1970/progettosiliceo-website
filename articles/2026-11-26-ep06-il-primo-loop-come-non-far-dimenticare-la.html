Ep. 06 — Il Primo Loop: come non far dimenticare la frase precedente al programma

Ieri il nostro agente ha risposto una volta sola. Poi ha chiuso gli occhi. Se gli chiedi «Come mi chiami?», non lo sa: non ha tenuto il tuo nome. La memoria di una chat non vive nel modello — è il tuo programma che gli rilegge ogni volta la storia dall'inizio. Oggi impariamo a fargliela rileggere.

Il cuore: il ciclo che non molla

Immagina un quaderno. Ogni volta che parli, scrivi la tua frase. Ogni volta che l'AI risponde, scrivi la sua. Prima di mandare tutto al "cameriere" (l'API), leggi l'intero quaderno ad alta voce. Così l'AI sa tutto ciò che si è detto finora.

In Python questo quaderno è una lista chiamata messaggi. Il gesto di «leggi, chiedi, scrivi, ripeti» è un ciclo while True: gira all'infinito finché non dici «basta».

python
# agente_loop.py — Il primo agente che ricorda
import os
import requests

# 1. Il quaderno della conversazione: una lista di dizionari
#    Ogni dizionario ha 'role' (chi parla) e 'content' (cosa dice)
messaggi = [
    {"role": "system", "content": "Sei un assistente gentile e sintetico."}
]

# 2. Chiavi e indirizzi (mettili nel tuo .env o sostituisci qui)
API_KEY = os.getenv("OPENROUTER_API_KEY", "LA_TUA_CHIAVE_QUI")
URL = "https://openrouter.ai/api/v1/chat/completions"
MODEL = "openai/gpt-4o-mini"   # modello economico e veloce per test

headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

print("Agente avviato. Scrivi 'esci' per chiudere.\n")

# 3. Il ciclo principale: gira finché non intervieni tu
while True:
    # 3a. Leggi l'utente
    tuo_testo = input("Tu: ")
    if tuo_testo.strip().lower() == "esci":
        print("A dopo!")
        break

    # 3b. Scrivi la tua frase sul quaderno
    messaggi.append({"role": "user", "content": tuo_testo})

    # 3c. Prepara il pacchetto per il cameriere (API)
    payload = {
        "model": MODEL,
        "messages": messaggi,       # <-- qui c'è TUTTA la storia
        "temperature": 0.3,
        "max_tokens": 300
    }

    # 3d. Manda e ricevi
    risposta = requests.post(URL, headers=headers, json=payload, timeout=20)
    dati = risposta.json()
    testo_ai = dati["choices"][0]["message"]["content"]

    # 3e. Mostra la risposta e scrivila sul quaderno
    print(f"AI: {testo_ai}\n")
    messaggi.append({"role": "assistant", "content": testo_ai})
