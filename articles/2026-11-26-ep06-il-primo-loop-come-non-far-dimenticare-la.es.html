Ep. 06 — El Primer Loop: cómo evitar que el programa olvide la frase anterior

Ayer nuestro agente respondió una sola vez. Luego cerró los ojos. Si le preguntas «¿Cómo me llamo?», no lo sabe: no ha guardado tu nombre. La memoria de un chat no vive en el modelo — es tu programa el que le relee cada vez la historia desde el principio. Hoy aprendemos a hacer que la relea.

El corazón: el ciclo que no suelta

Imagina un cuaderno. Cada vez que hablas, escribes tu frase. Cada vez que la IA responde, escribes la suya. Antes de mandar todo al «camarero» (la API), lees el cuaderno entero en voz alta. Así la IA sabe todo lo que se ha dicho hasta ahora.

En Python este cuaderno es una lista llamada messaggi. El gesto de «leer, preguntar, escribir, repetir» es un ciclo while True: gira al infinito hasta que dices «basta».

python
# agente_loop.py — El primer agente que recuerda
import os
import requests

# 1. El cuaderno de la conversación: una lista de diccionarios
#    Cada diccionario tiene 'role' (quién habla) y 'content' (qué dice)
messaggi = [
    {"role": "system", "content": "Eres un asistente amable y sintético."}
]

# 2. Claves y direcciones (ponlas en tu .env o sustitúyelas aquí)
API_KEY = os.getenv("OPENROUTER_API_KEY", "TU_CLAVE_AQUÍ")
URL = "https://openrouter.ai/api/v1/chat/completions"
MODEL = "openai/gpt-4o-mini"   # modelo económico y rápido para tests

headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

print("Agente iniciado. Escribe 'salir' para cerrar.\n")

# 3. El ciclo principal: gira hasta que intervengas tú
while True:
    # 3a. Lee al usuario
    tuo_testo = input("Tú: ")
    if tuo_testo.strip().lower() == "salir":
        print("¡Hasta luego!")
        break

    # 3b. Escribe tu frase en el cuaderno
    messaggi.append({"role": "user", "content": tuo_testo})

    # 3c. Prepara el paquete para el camarero (API)
    payload = {
        "model": MODEL,
        "messages": messaggi,       # <-- aquí está TODA la historia
        "temperature": 0.3,
        "max_tokens": 300
    }

    # 3d. Envía y recibe
    risposta = requests.post(URL, headers=headers, json=payload, timeout=20)
    dati = risposta.json()
    testo_ai = dati["choices"][0]["message"]["content"]

    # 3e. Muestra la respuesta y escríbela en el cuaderno
    print(f"IA: {testo_ai}\n")
    messaggi.append({"role": "assistant", "content": testo_ai})

Qué hace cada pieza, línea por línea

Línea(s)Qué ocurre
4–6Creamos el cuaderno (messaggi) con una regla inicial (system).
9–13Leemos la clave API y preparamos la dirección del camarero.
15–19La cabecera que el camarero exige para saber quién pregunta.
22Iniciamos el ciclo infinito (while True).
24–27Esperamos que escribas; si escribes «salir», salimos del ciclo (break).
30Añadimos tu frase al cuaderno.
33–38Construimos el paquete: modelo + todo el cuaderno + parámetros.
41Enviamos la petición con un timeout de 20 segundos (seguridad).
42–43Extraemos solo el texto de la respuesta del JSON que vuelve.
46–47Imprimimos la respuesta y la archivamos en el cuaderno para el siguiente turno.
