Ep. 04 — Il Banco di Lavoro: cos'è il Terminale, Python e il nostro primo file

Ieri abbiamo lasciato l'AI con la sua lavagna piena e il conto che sale. Ma prima di farle fare la prima vera chiamata, dobbiamo preparare il banco di lavoro. Niente di complicato: solo un angolo pulito dove scrivere le nostre istruzioni e vederle eseguire.

Il Terminale: una chat col tuo computer

Immagina di sederti alla scrivania e aprire una finestra dove scrivi comandi a parole, uno per riga. Il computer legge, esegue e ti risponde testualmente. Niente icone, niente menu: solo parole. È come mandare un messaggio a un collega molto veloce e molto letterale: fa esattamente ciò che scrivi, né più né meno.

Su Windows si chiama PowerShell (o "Prompt dei comandi"). Su Mac e Linux è il Terminale. Cercalo nel menu Start o con Cmd+Spazio → "Terminale". Aprilo. Vedrai una riga che lampeggia, in attesa. Quello è il tuo banco.

Python: la lingua per dare istruzioni

Il terminale capisce comandi di sistema (cd, ls, mkdir…), ma per scrivere logica — cicli, scelte, memoria — usiamo un linguaggio più espressivo: Python. Lo leggi quasi come l'italiano. È installato quasi ovunque; se digiti python --version (o python3 --version) e vedi un numero tipo 3.11.x, sei pronto. Altrimenti scaricalo da python.org (pulsante grosso "Download Python").

La nostra cartella di lavoro

Creiamo un posto ordinato per i nostri esperimenti. Nel terminale:

bash
mkdir -p ~/agente-lab
cd ~/agente-lab

mkdir = make directory (crea cartella). -p = non lamentarti se esiste già. cd = change directory (entra dentro). Ora sei dentro agente-lab. Tutto ciò che scriverai d'ora in poi starà qui.

Il primo file: 5 righe che salutano e ricordano

Crea un file chiamato banco.py (usa il Blocco note, VS Code, o notepad banco.py nel terminale). Incolla esattamente questo:

python
# banco.py — Il nostro primo banco di lavoro

nome = "Silicea"                    # 1. Una variabile: un'etichetta su un valore
memoria = []                        # 2. Una lista vuota: il nostro quaderno
memoria.append("Prima accensione")  # 3. Scriviamo la prima pagina
memoria.append("Terminale aperto")  # 4. Seconda pagina

print(f"Ciao, sono {nome}.")        # 5. Parliamo: mostriamo a video
print("Finora ho annotato:")
for riga in memoria:                # 6. Leggiamo il quaderno, riga per riga
    print(f" - {riga}")

Cosa fa ogni riga:

  • # → commento: lo ignora il computer, serve a te.
  • nome = "Silicea" → crea un'etichetta nome legata al testo "Silicea".
  • memoria = [] → prepara una lista vuota (parentesi quadre = contenitore ordinato).
  • .append(...) → infila un elemento in fondo alla lista.
  • print(...) → scrive sullo schermo. La f"..." permette di infilare variabili dentro il testo con {variabile}.
  • for riga in memoria: → "per ogni elemento nella lista, fanne questo". L'indentazione (spazi all'inizio) dice cosa sta dentro il ciclo.

Provalo

Nel terminale (dentro ~/agente-lab):

bash
python banco.py

Vedrai:

text
Ciao, sono Silicea.
Finora ho annotato:
 - Prima accensione
 - Terminale aperto

Il tuo programma ha memoria: ha conservato due righe e te le ha rilette. È vivo sul PC, ma è ancora muto. Domani gli facciamo fare la prima domanda a un'AI vera tramite un cameriere digitale.

Dove ci fermiamo oggi

Hai aperto il terminale, creato una cartella, scritto un file Python che saluta e tiene una piccola lista in memoria. Niente cloud, niente chiavi API, niente magie: solo codice che gira tuo sul tuo computer.

Domani — Ep. 05 — vedremo cos'è una API (l'analogia del cameriere al ristorante) e faremo la prima chiamata vera a un modello. Nel frattempo, rileggi banco.py, cambia il nome, aggiungi righe alla memoria, rompilo e rimettilo a posto. La confidenza si fa toccando.
