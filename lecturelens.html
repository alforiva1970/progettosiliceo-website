Architettura del Laboratorio

Studio Tattico Privato

LectureLens è un'applicazione web architettata dal Progetto Siliceo per eliminare la frammentazione nella preparazione degli esami accademici. Sfrutta l'incredibile potenza multimodale di Gemini 3.1 Flash operando direttamente nel browser: totale controllo dei dati personali, zero tracciamento, nessun costo occulto.
[01 // WEBASSEMBLY FFMPEG]

Estrazione Audio & Video

Identifica i fotogrammi salienti di una lezione registrata (lavagne, proiezioni) ed estrae la traccia vocale direttamente all'interno del browser, senza transitare su server remoti.

[02 // INGESTION MULTIMODALE]

Sbobinamento Integrato

Incrocia la trascrizione audio con l'ispezione ottica delle slide e della lavagna, producendo appunti cronologici coerenti, rigorosi e privi di ridondanze parassite.

[03 // SINTESI & FORMULE LATEX]

Elaborazione Slide & PDF

Elabora dispense universitarie e capitoli di manuali: isola i concetti cardine, schematizza le definizioni e formatta formule scientifiche con supporto LaTeX nativo.

[04 // ACTIVE RECALL RIGIDO]

Simulazioni d'Esame

Genera batterie di test a scelta multipla e quesiti a risposta aperta calibrati sulla reale complessità accademica del materiale didattico caricato in sessione.

[✦ ANTEPRIMA OPERATIVA // PRIVATE ALPHA]

Accesso al Banco di Prova

LectureLens è attualmente in fase di testing su GitHub Pages. L'architettura è interamente client-side: per iniziare la sessione di studio è sufficiente inserire la propria API Key di Google (BYOK).
