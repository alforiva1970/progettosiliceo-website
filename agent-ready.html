Vetrina Opt-In (Casi Studio Consenzienti)

CLI Open-Source Locale in Rust (AGPL-3.0)

Puoi compilare ed eseguire le stesse verifiche endpoint in autonomia da terminale con la CLI nativa in Rust del laboratorio (concorrenza parallela, anti-SSRF anche su risoluzione DNS pre-socket): 

cargo run --manifest-path tools/siliceo-audit-rs/Cargo.toml -- check https://progettosiliceo.online
cargo run --manifest-path tools/siliceo-audit-rs/Cargo.toml -- validate-ard ai-catalog.json
cargo run --manifest-path tools/siliceo-audit-rs/Cargo.toml -- observatory data/observatory.json
